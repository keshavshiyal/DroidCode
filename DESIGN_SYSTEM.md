# DroidCode Design System

DroidCode features a clean, high-contrast, developer-focused visual identity designed specifically for mobile and tablet code editing ergonomics.

## Aesthetic Personality

- **Professional & Minimal**: Restrained, purposeful UI surfaces without distracting decorations.
- **High Readability**: High-contrast syntax and UI typography optimized for long coding sessions.
- **Calm Neutral Palette**: Deep charcoal dark theme and warm neutral light theme.
- **Dense & Compact**: High information density suited for complex code navigation.

## Typography System

- **UI Elements**: System Sans-Serif (`Roboto` / System Default) - Clean, legibly sized for touch targets.
- **Code & Terminal**: System Monospace (`JetBrains Mono` / `Monospace`) - Fixed-width, crisp alignment for code columns and line numbers.

## Developer Quick Key Bar

Positions sticky keyboard modifiers (`Ctrl`, `Shift`, `Alt`), navigation keys, symbol brackets (`{`, `}`, `[`, `]`, `<`, `>`), and quick syntax operators directly above the keyboard/status bar area with customizable density.
