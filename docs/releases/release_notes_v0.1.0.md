# Release Notes v0.1.0-alpha01

Initial Phase 1 Foundation release of DroidCode.

Highlights:
- Full native Android IDE shell built on Java & Jetpack Compose
- Real filesystem and workspace management
- Real multi-tab editor with save, undo/redo, cursor state
- Developer Quick Key Bar with modifier key support
- Command Palette and Command System
- Persisted Dark and Light theme options
- Modular provider interfaces for Git, Terminal, DB, AI, and Extensions
